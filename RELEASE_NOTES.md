# Latestwise 1.0.0

Latestwise 1.0.0 is the first official GitHub release of the redesigned Windows application.

![Latestwise home screen](https://raw.githubusercontent.com/KSAGlory/Latestwise/main/assets/screenshots/latestwise-home-light.png)

## Included

- Local checks for DOCX, XLSX, PPTX, and PDF documents.
- User-approved folder scanning.
- Bounded local content extraction and SHA-256 fingerprinting.
- Deterministic comparison with clear uncertainty states.
- Possible-copy review with supporting evidence.
- Safe Open file and Show in File Explorer actions.
- Light, dark, and Windows appearance preferences.
- A complete Latestwise visual identity and interface redesign.
- No account, uploads, advertising, analytics, or background scanning.

## Safety

Latestwise does not replace, rename, move, or delete documents. It checks only the folders selected by the user.

## Compatibility

- Windows 11 version 22H2 or newer
- x64 and ARM64 desktop systems

**ARM64 notice:** The ARM64 build is included but has not been validated on physical ARM64 hardware. x64 is the officially tested configuration.

This is the official GitHub release. Microsoft Store packaging and publication remain a separate future phase.

## Verification

- 30 automated tests passed.
- The x64 and ARM64 Release builds completed with zero warnings and zero errors.
- The public packages were checked to contain no source code or debugging symbols.
